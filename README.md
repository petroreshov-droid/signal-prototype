# Авито + Сигнал · кликабельный концепт

Прототип команды «ООО «Коммерсы»» для кейса Авито на Changellenge Cup Moscow 2026.
Концепт, не является продуктом Авито. Данные вымышлены, оплата не настоящая. Знатоки и друзья в прототипе - боты.
Аккаунт создаётся без телефона и пароля и хранится только в браузере устройства.

Открыть: https://petroreshov-droid.github.io/signal-prototype/
